# Plan: タスクバーの右クリックメニューの調整

## 実装状況: 未着手

> 出典: オーナー指示（2026-10-24）

## 関連 Plan

- [window-overlap-avoidance.md](window-overlap-avoidance.md) — メニューに出すトグル「フルスクリーンを避ける」は、同 Plan で追加した設定
  `exitFullScreenToAvoidTaskbar`（設定画面の「フルスクリーン: 解除して避ける」）を切り替える
- [taskbar-app-combining.md](taskbar-app-combining.md) — 結合ボタンの右クリックメニューは本 Plan の構成を前提にする

## 目的

タスクバー上の右クリックから、よく使う設定（フルスクリーンを避ける）と設定画面に直接たどり着けるようにする。
あわせて、タスクのピン留め項目の名前を実態に合わせる。

## 現状の挙動

- タスクの右クリック: `context_menu.rs` がネイティブメニューを出す。項目は「先頭へ追加（先頭から削除）」「末尾へ追加（末尾から削除）」
  「閉じる」「強制終了」の 4 つ
- タスクのない箇所の右クリック: 専用のメニューはない（WebView の既定の挙動）
- 設定画面へは、ロゴのクリックで出るメニューウィンドウ（`context_logo`）からたどる

## 変更内容

### 項目 1: タスクの右クリックメニュー

```
先頭にピン留め
末尾にピン留め
閉じる
強制終了
────────────
✓ フルスクリーンを避ける
設定
```

- 「先頭へ追加」「末尾へ追加」を「先頭にピン留め」「末尾にピン留め」に改名する。
  ピン留め済みのときの表示は「先頭のピン留めを外す」「末尾のピン留めを外す」にする（現在の「先頭から削除」「末尾から削除」の改名）
- 強制終了の下にセパレータを置き、その下に「フルスクリーンを避ける」（チェック付きのトグル）と「設定」を足す
- **対象**: `src-tauri/src/context_menu.rs`（ラベル・項目・ハンドラ）、同ファイルのテスト（ラベルの期待値）

### 項目 2: タスクのない箇所の右クリックメニュー

```
✓ フルスクリーンを避ける
設定
```

- タスクバーの余白（タスクボタン以外）で右クリックしたときにだけ出す。タスクボタン上の右クリックは項目 1
- フロント（`pages/index.vue`）で余白の `contextmenu` を受け、新コマンド（例: `contextTaskbar`）を呼ぶ。
  WebView の既定メニューは `preventDefault` で抑止する
- **対象**: `context_menu.rs`（メニュー構築を共通化）、`commands.rs`（新コマンド・`lib.rs` への登録）、`pages/index.vue`

### 項目 3: 共通項目の動作

- 「フルスクリーンを避ける」: `exitFullScreenToAvoidTaskbar` を反転して保存し、`updateOptions` を emit する
  （設定画面を開いていれば表示も追従する）。チェック状態は保存値から作る
- 「設定」: 既存の `open_option`（設定画面を開くコマンド）と同じ処理を呼ぶ
- メニュー項目 ID は既存どおり `context-task-` 系の接頭辞で衝突を避ける。ハンドラは lib.rs で 1 回だけ登録する既存方式に載せる

## 解釈と確認事項

- 「フルスクリーンを避ける」は、重なり回避の「フルスクリーンを解除して避ける」（`exitFullScreenToAvoidTaskbar`）の
  トグルと解釈した。重なり回避そのもの（`autoAvoidTaskbarOverlap`）のオン・オフを意図していた場合は、項目名とつなぐ設定を差し替える
  （確信度 7 割。違えばオーナーが指摘する）
- 重なり回避がオフのとき、「フルスクリーンを避ける」は効かない。メニューでは無効表示（グレーアウト）にする

## 影響範囲

- フロント: `pages/index.vue`（余白の右クリック）
